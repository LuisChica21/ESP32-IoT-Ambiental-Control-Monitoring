About the Project
This IoT system allows users to monitor and control different environmental parameters through a local dashboard, while also providing remote notifications through a Telegram chatbot.

The system can:

Monitor temperature in real time.
Monitor humidity in real time.
Monitor the Wi-Fi connection status.
Control devices such as an LED.
Control a fan for temperature regulation.
Use a configurable temperature threshold to automatically activate the fan and help stabilize the temperature.
Send and receive project status notifications through a Telegram chatbot.
Receive and store all collected data in a database.
Display system information through a local dashboard.
How It Works
The system continuously collects environmental and connectivity data. The measured temperature is compared against a predefined threshold.

When the temperature exceeds the configured limit, the fan can be activated automatically to help reduce and stabilize the temperature.

At the same time, the collected information is stored in a database and displayed on the local dashboard. The Telegram chatbot provides an additional communication channel for receiving notifications and checking the project's status remotely.

Gracias
Gracias por descargar y explorar este repositorio. Agradecemos mucho tu interés en este Sistema IoT de Monitoreo y Control Ambiental.

Este proyecto fue desarrollado para integrar IoT, monitoreo ambiental, automatización, gestión de bases de datos y comunicación mediante Telegram en un solo sistema.

Acerca del Proyecto
Este sistema IoT permite monitorear y controlar diferentes parámetros ambientales mediante un dashboard local, además de proporcionar notificaciones remotas a través de un chatbot de Telegram.

El sistema permite:

Monitorear la temperatura en tiempo real.
Monitorear la humedad en tiempo real.
Monitorear el estado de la conexión Wi-Fi.
Controlar elementos como un LED.
Controlar un ventilador para regular la temperatura.
Utilizar un umbral de temperatura configurable para activar automáticamente el ventilador y ayudar a estabilizar la temperatura.
Enviar y recibir notificaciones sobre el estado del proyecto mediante un chatbot de Telegram.
Recibir y almacenar todos los datos obtenidos en una base de datos.
Mostrar la información del sistema mediante un dashboard local.
Funcionamiento
El sistema recopila continuamente información ambiental y de conectividad. La temperatura medida se compara con un umbral previamente establecido.

Cuando la temperatura supera el límite configurado, el ventilador puede activarse automáticamente para ayudar a disminuir y estabilizar la temperatura.

Al mismo tiempo, la información recopilada se almacena en una base de datos y se muestra en el dashboard local. El chatbot de Telegram proporciona un canal adicional de comunicación para recibir notificaciones y consultar el estado del proyecto de forma remota.
